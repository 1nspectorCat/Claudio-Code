# Claudio Code — установка своего релея (SETUP)

Рация не имеет общего сервера: каждый пользователь поднимает СВОЙ мост.
Контур из трёх частей:

```
Claude Code (твой компьютер)                твой сервер (любой VPS)      телефон
Stop-hook озвучивает ответ  ── HTTPS ──▶  relay.js (Node, порт 8443) ◀── Claudio Code (APK)
и шлёт OGG на релей                        очереди сессий, /utt, WSS      играет ответы, шлёт голос
```

## 1. Сервер (5 минут)

Нужен любой Linux-сервер с публичным IP (самый дешёвый VPS подходит).

1. Установи Node.js 18+.
2. Скопируй `server/relay.js` и `server/install-relay.sh` из этого репозитория
   в одну папку и запусти:
   ```bash
   bash install-relay.sh
   ```
   Скрипт сам сгенерирует токен и сертификат, запустит релей и напечатает
   **ссылку-настройку** (`claudio://setup?...`) и её QR-код.
3. Ручной путь (если скрипт не подходит). Релей читает настройки ТОЛЬКО из
   `config.json` рядом с собой:
   ```bash
   npm install ws
   openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 3650 -subj "/CN=relay"
   TOKEN=$(head -c 24 /dev/urandom | base64 | tr -d '+/=')
   printf '{ "token": "%s", "port": 8443, "tlsKey": "key.pem", "tlsCert": "cert.pem", "keepAudio": 100 }\n' "$TOKEN" > config.json
   openssl x509 -in cert.pem -outform DER | sha256sum | awk '{print $1}'   # ПИН — только hex, без « -»
   ```
   и запусти relay (лучше через pm2): `node relay.js`.

## 2. Компьютер с Claude Code (10 минут)

1. Скопируй `desktop/readback.py` в `~/.claude/voice/` и заполни
   `config.json` (адрес релея, токен).
2. Зарегистрируй его Stop-хуком в `~/.claude/settings.json` — каждый ответ
   сессии будет озвучиваться (edge-tts + ffmpeg) и уезжать на релей.
3. В сессии подними поллер входящих (скилл voice-bridge из репозитория).

## 3. Телефон (1 минута)

1. Установи приложение.
2. Отсканируй камерой QR-код со своего сервера (или открой ссылку
   `claudio://setup?...`) — адрес, токен и отпечаток встанут сами.
   Запасной путь: настройки → «для продвинутых» → вставить одной строкой
   `адрес|токен|пин` (или JSON).
3. Нажми круг и скажи «привет». Всё.

## Whisper (необязательно, для продвинутых)

По умолчанию распознавание идёт средствами Android. Если хочешь серверное
распознавание (лучше в шуме) — поставь на сервер whisper.cpp и `transcribe.js`
из репозитория, раздел «для продвинутых» в приложении, тумблер Whisper.
